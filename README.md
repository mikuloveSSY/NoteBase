# NoteBase

当前软件版本为 **0.2.0，成员一存储初版**。可运行工程位于 [notebase-starter](notebase-starter/README.md)，原始 0.1.0 ZIP 保留归档。

本版基于已有主干增强文件存储，并完成 Windows 桌面集成。检索、索引、自动保存等尚未实现。

- [成员一开发计划](docs/成员一开发计划.md)

- [本版验证记录](notebase-starter/docs/验证记录-v0.2.0.md)
