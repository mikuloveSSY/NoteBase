# 成员一交接总览 v0.7.0

日期：2026-10-29。源码在仓库 `notebase-starter/`，软件版本 0.7.0。文件为权威数据源，SQLite 放应用数据目录，不能放进笔记库。本文是成员二、三、四的当前接入入口；旧版交接文档记录当时行为，冲突时以本文和根目录 CHANGELOG 为准。

## 阅读与启动

先读根目录 CHANGELOG，再按负责范围阅读本文及 0.2–0.6 交接文档。安装与启动命令见 README；在工程目录执行 `npm ci`、`npm run desktop`，用独立测试库验证打开、新建、读取、保存、重开、检索。浏览器演示只修改内存，不验证磁盘。

## 当前接通范围

真实接通 11 个命令：vault_open、vault_info、note_list、note_create、note_read、note_save、search、index_status、index_rebuild、settings_get、settings_set。settings 只支持 vaultPath，不代表完整设置业务。

其余 12 个仍为明确报错的入口：note_rename、note_delete、note_restore、link_backlinks、link_mentions、link_graph、export_note、backup_create、backup_restore、sync_configure、sync_now、sync_status。底层 rename/delete 可用，不等于重命名链接、回收站或恢复业务已完成。

## 可直接联调的载荷

以下是 `call(command, payload)` 的 payload。底层请求信封沿用 Request/Response，见 domain.rs 和 contracts.ts。

```ts
await call('vault_open', { path: 'D:/NoteBase-demo' });
await call('search', { query: '"动态规划" -排除词', sort: 'relevance', limit: 50, cursor: null });
await call('search', { query: 'title:课程', filters: { tags: ['课程'], pathPrefix: '课程/' }, limit: 50 });
await call('index_status', {});
await call('index_rebuild', { mode: 'full' }); // 返回 jobId，继续消费状态事件
await call('settings_get', { keys: ['vaultPath'] });
// 显式复制并切库，目标必须不存在；普通打开现有库应调用 vault_open。
await call('settings_set', { values: { vaultPath: 'D:/NoteBase-migrated' } });
```

搜索返回 items、nextCursor、totalApprox、tookMs、degraded、degradeReason。totalApprox 沿用名字，实际为同一读事务内的精确总数；取下一页时查询、过滤、排序、limit 保持不变。索引 revision 改变后旧游标报错，从第一页重查。短词扫描和重建查询都可能降级，见检索及重建交接。空结果是成功且 items=[]，不可服务返回 E_INDEX_UNAVAILABLE，不应显示成正常零结果。

note_save 仍以 baseHash/已知原文哈希防覆盖；indexQueued 仅说明接收任务，snapshotCreated=false 不表示已有快照。未保存文本不得因外部通知而丢弃。clientSeq/expectedMtimeMs 尚未实现完整状态管理。

## 0.7.0 内部线程变化与兼容

桌面 search 只在短锁内取得 `App::search_session()` 的 Arc，实际查询在锁外执行。IndexFactory 现在返回 Arc<dyn IndexSession>，IndexSession 增加 Sync 和 cancel()；库切换/迁移/App 关闭显式取消旧会话。Rust 自定义工厂或实现者需要适配，当前仓库只有 BackgroundIndex 的生产实现。没有新增或更名 IPC 命令、事件、错误码、表和响应字段，TypeScript DTO 不变。该内部端口变更尚需其他成员在合并时评审，不能将本机测试写成全员协商通过。

查询复用两条独立只读连接，每条由 Mutex 保护。候选集合在读事务内物化一次，计数与分页共用，选出本页后才读正文片段；标题/别名/标签命中集合复用，匹配、权重、稳定排序和转义语义保持不变。长普通词以 FTS 的标题/正文候选约束标题 LIKE；无 ASCII 字母的短词先用 instr 做必要条件过滤，再由转义 LIKE 最终判定，保留字面符号和大小写语义。读连接最多映射 256 MiB 文件，页缓存每连接上限约 64 MiB；映射不等于预分配物理内存，不宣称整机内存验收通过。

发布大批索引后做 FTS 合并和 WAL 检查点，忙时 SQLite 保留 WAL；正常关闭先释放读连接再关闭写连接。四张业务状态表不变：snapshot_index、sync_state、sync_tombstone、rename_journal。归档恢复只能恢复已知字段，不保证未知扩展业务语义。

## 事件与生命周期

必须使用 contracts.ts 的 transportEventName 或 Rust domain::transport_event_name：例如 index.state → notebase:index_state，note.changed → notebase:note_changed。实际产生 note.changed、index.state、index.progress、error.raised；其他逻辑事件只是保留。indexQueued 与 index.state=ready 不能互相替代。

默认监听防抖 150 ms，周期对账 300 秒。监听失败会告警并轮询，轮询不承诺 1 秒可检索。外部变化可能让分页游标失效。旧会话取消后不接受新查询，正在查询也检查 active/代次并拒绝过期结果；不会把旧库结果当成新库结果返回。
