# 搜索弹窗验收

2026-11-01，从main 7234b20继续。用户要求将原搜索笔记的完整功能搬入弹窗，笔记库工具内提供入口。

## 行为与兼容

- “搜索笔记…”入口留在笔记库工具，搜索框、路径/标签筛选、排序、摘要/结果、分页、索引状态和重建/警告全部移入居中dialog。沿用遮罩、取消/高亮确定、字段下错误，支持Enter与Esc。
- 原搜索快捷键/命令/菜单直接打开弹窗，不要求先展开工具；后台重建命令也会打开搜索窗口以便查看状态。原控件ID保留，搜索请求继续使用原command、query/sort/filters/limit/cursor，不修改Rust或查询语法。
- 点击命中成功打开后关闭弹窗并定位原有摘要；读取/保存失败时保留弹窗和错误。取消/关闭后保留条件及结果；在途只读请求可完成但不会自动重新打开窗口。切库清空旧查询/结果并关闭弹窗，过滤输入沿用原有保留行为。
- 分页保存已提交的条件快照，输入变化即隐藏“更多”并废弃旧游标，避免使用新条件继续旧页。结果中的高亮仍仅解释受控b标记，其他内容以文本显示。
- 浏览器演示仍不提供磁盘全文检索，测试桥接响应仅验证前端请求与交互；真实查询、筛选和索引由exe验证。业务命令、事件、错误码、DTO、settings、SQL、Rust、依赖和0.7.0软件版本不变。
