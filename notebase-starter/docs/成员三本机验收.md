## PDF

`export_note` 原有 `format=pdf` 现返回真实 PDF。Windows 自动寻找 Chrome 或 Edge，使用独立临时配置运行无界面打印，不复用用户浏览器会话；沿用 HTML 渲染的内容安全策略和内嵌图片。30 秒超时，验证 PDF 头尾后才原子发布，已有目标不覆盖。未找到浏览器或非 Windows 返回 `E_PDF_UNSUPPORTED`。选择框说明浏览器依赖。

合成样张包含中文、英文、表格、代码块、引用和 45 个段落，共 3 页。已使用 pypdf 提取中文并用 PDFium 渲染逐页查看，无截断或乱码。实际验证浏览器为 Chrome；Edge 发现路径已实现，但未单独实测。长行代码、超宽表格和特殊字体仍可能需要排版适配。

生成可复现样张（目标需为不存在的绝对路径）：

```powershell
cargo run --manifest-path crates/notebase-core/Cargo.toml --example pdf_acceptance -- D:/Exports/acceptance.pdf
```

实现依据：[Chrome Headless 打印接口](https://developer.chrome.com/docs/automation-and-testing/headless-cli)。不增加顶层命令或修改数据库。

## 独立 WebDAV 与系统凭据

服务为独立 Python WsgiDAV 4.4.0 + Cheroot 11.1.2，非 Rust 内存模拟后端；只监听 127.0.0.1，使用临时空目录、随机端口和随机密码。Rust 经正式 `WebDav` HTTP 适配器及 `OsCredentials` 系统接口访问。

明确执行并通过：系统凭据写入/读取、重新打开服务后使用、清理后不可读取；中文嵌套路径上传、下载；本地与远端并发修改时保留冲突并显式解决；本地删除同步；错误密码拒绝；过期 ETag 写入拒绝；真实 TCP 连接拒绝后保留本地编辑、恢复连接后补传。应用测试目录逐文件扫描未发现随机密码。

复现（Windows、Rust、Python）：

```powershell
python -m venv ../../.venv-acceptance
../../.venv-acceptance/Scripts/python.exe -m pip install wsgidav==4.4.0 cheroot==11.1.2
../../.venv-acceptance/Scripts/python.exe scripts/accept_member3_webdav.py
```

脚本结束关闭服务并删除临时目录；测试使用独立 `acceptance-*` 凭据项并在退出时清理。不要替换为真实个人笔记目录。该用例默认 ignore，必须显式通过脚本运行；常规核心套件的跳过不能算作该项验收通过。
