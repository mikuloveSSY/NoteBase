# NoteBase 成员四集成版操作说明

本分支保留软件基线 0.6.0，尚未作为团队正式版本发布。Windows x64 运行需要 WebView2；便携 ZIP 解压后运行 notebase.exe。请先用测试库验收，再打开自己的笔记。

## 开始使用

1. 输入已有 Markdown 文件夹的绝对路径，选择“打开已有文件夹”。索引在后台创建，不阻塞编辑。
2. 点击笔记编辑。停止输入 2 秒或持续输入 10 秒触发自动保存；草稿每 500ms 调度。状态为“已保存”表示笔记写盘成功，索引与版本快照有独立状态。
3. 搜索支持中文、title:/tag:/path:，筛选支持标签、路径和排序。空结果、搜索错误及重建降级分别展示。演示网页不建立真实索引。
4. 编辑区上方提供轻量标签页；重启会恢复当前窗口、当前库的标签路径。正文不写入界面缓存。

## 设置与键盘

- 设置：主题（系统/浅/深）、字号 10–32、行宽 40–200 个字符、缩进 1–8、自动换行、布局入口。学生/研究者当前共用三栏；开发者隐藏右栏，写作者进入专注。
- 默认新建 Ctrl+N、搜索 Ctrl+Shift+F、保存 Ctrl+S、下一标签 Ctrl+Tab、命令面板 Ctrl+Shift+P。
- Windows 全局唤出默认 Ctrl+Shift+Space。更改快捷键若被占用，返回 E_KEYMAP_CONFLICT 并保留原配置。macOS/Linux 全局注册尚未实现。
- 专注模式隐藏左右栏，上方仍保留退出按钮。命令面板可搜索并用键盘选中操作。
- 浏览器演示的设置和布局保存在浏览器；笔记仍为内存演示，刷新后重置。

## 多窗口与数据保护

“新建窗口”打开同一库。每个窗口有独立 clientId，外部变化会核对保存基准。两个窗口编辑同一笔记时，过期写入被拒绝并要求显式处理冲突。

有多个窗口时禁止切库与目录迁移，请先关闭其他窗口。关闭窗口前冲刷保存；保存失败或冲突时保留窗口。标签切换也会先保存，当前实现不允许带着未处理冲突切换笔记。

外部修改冲突有三种显式选择：保留本地、使用磁盘、另存副本；关闭冲突对话框保持暂停。草稿恢复、回收站、重命名预演沿用成员二实现。

## 故障与日志

索引损坏可后台重建；目录迁移先校验复制，保留原目录。设置文件损坏时保留原件、报告错误，不覆盖坏文件。

日志位于应用数据目录 logs/，JSONL 按天记录，单个文件约 1 MiB 后滚动，保留 7 天。仅记录命令、错误码与时间，不记录正文、查询、附件、凭据或绝对路径。日志不会上传。

## 当前边界

预览、导出、备份、版本历史和同步等待成员三交付。界面不会把缺失服务标为成功。大库性能、macOS/Linux 真机、物理断电和签名安装器仍需团队专项验收。已生成未签名 NSIS 安装器及便携 ZIP；安装/卸载尚未测试，二者均为开发测试交付物。
