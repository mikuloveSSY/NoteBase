# NoteBase Windows 使用说明

本包为0.7.0开发候选版。可直接运行桌面软件；完整需求、安装升级、公网同步和最终规模性能仍在验收中。当前进度以仓库CHANGELOG和需求矩阵为准。

## 启动和打开笔记库

1. 解压整个ZIP，双击 `NoteBase.exe`，无需运行Node、Rust或终端。
2. 点击左侧“选择笔记库文件夹…”，在系统窗口中选中笔记目录即可打开；已有Markdown目录也可使用。取消选择会留在当前库。也可在下方输入路径后点击“按路径打开”。
3. 输入标题新建笔记。编辑后自动保存，也可按Ctrl+S。右侧显示索引状态，索引就绪后可检索中文内容。

需要Windows x64与Microsoft Edge WebView2 Runtime。已安装该运行库的机器可直接运行本包；未安装时需要先安装Microsoft官方WebView2 Runtime。当前包不含运行库，不是完整离线安装包。

笔记正文保存在你选择的文件夹，以普通UTF-8 Markdown和YAML元数据保存。库外的索引、草稿、版本和同步状态位于应用数据目录，不能一起当作缓存删除。此处的便携包指程序文件可搬移，用户数据仍按系统应用数据目录保存。

若打开时提示E_IO_PERMISSION，查看消息中的具体目录。笔记库会递归扫描子文件夹；父目录可访问，不代表所有子目录都可读。建议选用专用笔记文件夹，避免把包含受限测试目录或系统目录的整个项目/磁盘根目录当作笔记库。软件不会修改目录权限或静默忽略不可读内容。

## 编辑、查找和组织

- Ctrl+N新建、Ctrl+Shift+F检索、Ctrl+Tab切换标签、Ctrl+Shift+P打开命令面板。
- 标签、别名、收藏和属性直接保存在笔记frontmatter中。已有外部修改会提示核对，不静默覆盖。
- 文件删除进入库内trash；恢复遇同名会保留双方。彻底删除需二次确认。
- 双链、反向链接、未链接提及和重命名预演在右侧面板；重命名需要确认修改清单。若提示待恢复任务，在恢复面板继续执行，不要手工清除日志。

## 版本、备份与恢复

- 保存时记录版本；也可创建手动笔记快照并填写说明。版本可查看原文、对比和回滚。
- “版本历史保留天数”默认30天，可修改；0表示关闭新版本记录和自动清理，已有版本保留，重新启用后恢复显示并按所设天数清理。
- 改名时历史跟随笔记迁移；如果已有旧笔记历史占用了目标名称，将明确拒绝，避免混合两篇笔记的历史。
- 整库ZIP含清单和附件，可先“仅校验”。恢复前会额外创建整库快照；恢复当前库时保留原目录。多窗口下先保存并关闭其他窗口。
- 如果恢复发布与回退均失败，软件会显示原库保留目录和快照路径；保留这些文件，重新打开原库保留目录。不要删除原件或把取消理解为撤销全部操作。

## 导出与同步

MD/HTML/整库ZIP可从右侧导出，目标需为库外绝对路径且不覆盖已有目标。Windows PDF使用已安装Chrome或Edge；A4、目录页码、复杂排版与独立浏览器验收仍在完善。

WebDAV可选，默认未配置时不向任何同步目标传输。填写自己的HTTPS地址与凭据，密码进入系统凭据库。冲突保留双份供手动处理，普通同步检查更新后再确认本地结果；远端又有新内容时旧确认会被拒绝。公网供应商/代理验收未完成，不把本机环回通过当成公网保证。

## 升级与来源校验

退出软件后替换程序文件，保留笔记库和应用数据。升级/降级前另存整库备份及库外版本/同步状态；本轮私有状态的兼容边界见仓库验收记录。

同目录build-manifest.json记录软件版本、来源提交与开发状态；SHA256SUMS.txt记录本exe校验值，ZIP旁另有.sha256。正式发布前还需关闭需求矩阵中的剩余验收项；此文件不将开发候选版称为完全版。
