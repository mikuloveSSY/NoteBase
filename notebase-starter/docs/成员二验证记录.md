## 运行

在notebase-starter目录，正常Rust/MSVC环境直接运行上述cargo/npm命令。本工作区隔离环境示例：

~~~bash
bash ../../.notebase-tools/rust/with-rust.sh cargo test --locked --offline --manifest-path crates/notebase-core/Cargo.toml
bash ../../.notebase-tools/rust/with-rust.sh npm run desktop:build -- --no-bundle
bash ../../.notebase-tools/rust/with-rust.sh npm run test:desktop
~~~

启动器使用工作区TEMP，避免系统临时目录间歇删除失败。浏览器测试采用polling避免Vite在源码原子编辑期间遇EBUSY；不改正式应用数据规则。

## 边界

- 200次强杀只覆盖服务已确认持久化的内容，不等于物理断电，不能推导任意未确认输入的99%恢复率。
- 自动保存时序有可控时钟与真实桌面验收；慢盘、物理写满、断电专项未运行。
- macOS/Linux、安装包、10万/20万篇及1MiB输入P95未验收。链接扫描/列表不声称规模性能达标。
- 原存储check→write外部竞争仍待句柄级保护；未引入系统沙箱替代。
- 索引增量/原生watcher、版本快照/备份、渲染导出、多窗口由对应成员继续集成，未接入时状态如实false。
