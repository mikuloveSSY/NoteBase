# NoteBase 1.0.0 正式版

发布日期：2026-11-02。按用户明确决定，将当前已整合功能定为1.0.0正式版；Windows x64为本次二进制交付平台。发布版本不代表原82条需求及所有环境已全部验收，未完成项继续追踪，不改写历史测试结果。

## 功能范围

本地Markdown笔记库、自动保存/草稿恢复、标签与属性、模板/附件/回收站、多标签页与同库多窗口、双链/反链/图谱、中文全文检索与后台索引、Markdown分栏预览、导出/快照/备份恢复、WebDAV配置、软件内输入与搜索弹窗。包含最新混合文件夹扫描与关闭响应修复；不要选择NoteBase工程/运行目录作为笔记库。

## 安装与数据

GitHub发布页：<https://github.com/mikuloveSSY/NoteBase/releases/tag/v1.0.0>。安装器、便携ZIP与SHA256随发布提供；本机交付位置及核验记录见[最新版安装包与清理记录](最新版安装包与清理记录.md)。安装器按当前用户安装，缺少WebView2时需要联网获取。便携包解压后双击NoteBase.exe，不需要Node/Rust。

升级前保存并关闭旧程序，备份笔记目录及应用数据目录，再安装1.0.0或解压到新目录；选择原笔记库。软件标识和数据位置保持不变，不执行数据格式迁移。回退前同样备份，保留新旧数据副本，勿在两个版本同时写同一库。卸载前备份；安装/升级/回退/卸载的数据保护尚无干净机完整实测，不能保证所有机器上的兼容结果。

用户操作见[Windows使用说明](Windows使用说明.md)，开发者入口见[工程README](../README.md)。文件是权威数据源；索引可重建，草稿、版本及同步状态不可一并当缓存删除。

## 已知限制

- 完整文件树操作、拖出标签窗口、角色布局、部分偏好/附件/收藏/筛选入口尚不完整。
- 维护任务期间保存依赖草稿与重试；不能保证所有任务下正文10秒内落盘。实际磁盘满/文件锁、随机写入中断仍需补验。
- 公网WebDAV、代理、供应商兼容与隐私抓包未完成；已有环回测试不能代替公网验证。
- PDF的完整A4/目录/页码/代码高亮及跨渲染器互操作仍需完善，Windows PDF需要Chrome或Edge。
- 干净机安装/升级/卸载、无WebView2环境、macOS/Linux、网络盘、十万/二十万笔记最终性能及真人可用性仍待验证。
- 旧重命名历史修复、部分契约差异与团队评审继续追踪；详见[需求矩阵](../../docs/需求完成矩阵与发布阻塞清单.md)的RB-01至RB-09。RB-10的版本/文档/标签交付按本次用户决定执行，其他未测门槛不视为通过。
