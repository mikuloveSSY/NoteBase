## Rust 核心测试覆盖

1. 新建、读取、保存、磁盘内容及返回哈希一致；保存后不遗留临时文件。
2. 同名新建生成序号，不覆盖已有文件。
3. 拒绝目录穿越、绝对笔记路径、反斜杠和系统保留名。
4. 旧版本保存被拒绝，磁盘内容不变。
5. 外部修改被检测且保留，不被当前编辑覆盖。
6. UTF-8 BOM 和 CRLF 在保存后保持。
7. 非法 YAML 原文保持，返回解析错误。
8. 合法 frontmatter 被识别，原文仍完整返回。
9. 未实现命令不返回成功。
10. 列表分页及回收站目录排除。
11. 非 UTF-8 文件返回错误且原字节保持。
12. Linux 符号链接不能指向库外文件。

## 范围说明

浏览器测试使用内存演示适配器，不能代替 Tauri 桌面到磁盘的端到端验证。真实磁盘路径由 Rust 核心测试覆盖，桌面集成需在小组的 Windows 机器完成。测试未覆盖断电、Windows 文件锁、磁盘写满、目录竞态、跨窗口、多平台及大规模语料。

原交接包提到的 evidence 实测脚本与附件本次未提供，因此未尝试复跑原性能数据，也未更改原文中的数字。
