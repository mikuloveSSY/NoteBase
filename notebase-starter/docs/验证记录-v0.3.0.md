Rust 新测试覆盖十表结构、只读连接、WAL、中文跨字 trigram 命中、FTS 内容副本、批次失败整体回滚、幂等更新/删除/链接状态、单写者锁、版本值变化后四张业务状态表保留、未知结构/身份/损坏拒绝覆盖、comrak 抽取、无效编码与大文件拒绝建立假索引、205 篇真实库分批构建和刷新、空库、取消、构建期间保存、索引初始化失败后仍可编辑并重新打开恢复。

真实桌面测试通过界面和 Tauri IPC 操作独立临时库，并用 Node 内置 SQLite 只读连接检查实际数据库中的标题、标签、trigram 命中和刷新后的正文。验证数据库在笔记库外、扫描不改源文、保存后状态过期、重开刷新、切库相互隔离。使用 NOTEBASE_DATA_DIR 与独立 WebView2 配置，未写入日常应用索引；测试输出/截图/缓存不提交 Git。原 0.2.0 的四项桌面读写保护测试仍通过。

本轮发现 Vite 默认监听 Rust target 目录，编译 SQLite 时遇到 EBUSY 导致浏览器测试服务退出；已将 target、test-results 和 playwright-report 排除出监听，浏览器回归随后通过。测试回调曾有 Rust 类型错误，修正后完整核心测试与 Clippy 通过。

本次没有进行 10 万/20 万篇性能、物理磁盘写满、断电、网络盘、macOS/Linux 或安装包验收。205 篇测试是正确性测试，不是规模性能证据。没有验证尚未实现的全文检索业务、增量监视、完整重建迁移。接口取舍与已知边界见 [索引基础交接](索引基础交接.md)。
