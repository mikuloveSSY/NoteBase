## 复现

在 `notebase-starter/` 运行（依赖已安装）：

```powershell
cargo test --locked --manifest-path crates/notebase-core/Cargo.toml
cargo clippy --locked --manifest-path crates/notebase-core/Cargo.toml --all-targets -- -D warnings
cargo clippy --locked --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings
cargo fmt --manifest-path crates/notebase-core/Cargo.toml -- --check
cargo fmt --manifest-path src-tauri/Cargo.toml -- --check
npm test
npm run build
$env:PLAYWRIGHT_CHANNEL='msedge'
npm run test:e2e -- --workers=1
npm run desktop:build -- --no-bundle
npm run test:desktop
npm run tauri -- bundle --bundles nsis --ci --no-sign
./scripts/package-portable.ps1
```

`scripts/verify.ps1` 封装测试/检查/EXE 构建，不自动安装安装包。本机 NSIS 工具从 Tauri 指定官方地址下载并校验，使用临时 useLocalToolsDir 配置完成打包；此路径不是队友必须照搬的步骤。
