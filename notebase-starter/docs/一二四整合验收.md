## 关键集成行为

- NoteService 始终负责保存、草稿、客户端基准、冲突、回收站与链接。实际落盘变更统一 drain 后送入 IndexQueue，部分重命名失败也追赶已完成路径；草稿和预演不引发伪索引更新。
- 同库 reopen 保留 NoteService 和已有客户端基准，复用可刷新的索引会话。search_session 返回 Arc，在 Tauri 短锁内取得后锁外查询，保留日志；切库、迁移和 App drop 显式 cancel，拒绝旧会话结果。
- 迁移继续校验完整清单、大小和哈希，配置提交前读取复制的草稿与重命名日志，按新 vault_id 重新装配；保留原库。窗口在切换前 flush/close，按库代次丢弃迟到响应。多窗口时继续禁止切库与迁移。
- UI 保留成员四偏好、标签恢复和窗口入口，统一为一套搜索控件及事件订阅，保留 main 的安全文本/mark 片段高亮与跳转定位、路径/标签/排序筛选、大库提示。
- 成员三六个保留命令明确报未实现；SaveResult.snapshotCreated=false；设置更新保留其他成员已有键；四张业务状态表继续保留。共用解析、快照和恢复维护边界见[成员三接入约定](成员三接入约定.md)。

## 失败记录和修正

1. 首次并发测试失败：测试只装配 App::new 与索引工厂，未装配成员二新增存储支持，vault_open 失败导致无 search_session。改为完整 new_local_app 装配，对两个 open 均断言成功；原“查询不占 App 锁、切库取消”断言保留，并新增同库重开与退出取消验证。
2. 受限环境首次核心回归中，五项正常文件创建/保存测试失败；相同实现转到正常 Windows 权限执行后全通过。未将受限失败算通过，也未修改原文件安全断言。
3. 首轮浏览器服务受限启动后残留测试端口，正常环境报 1420 被占用；停止本轮启动的会话，确认释放后完整 15 项通过。未终止用户其他服务。
4. 合并过程中曾出现重复搜索 DOM/函数与冲突代码，提交最终集成前已收敛成单一实现并完成构建和 UI/桌面全回归。
